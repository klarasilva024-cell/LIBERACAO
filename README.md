# Sistema Automatizado de Liberação da Fila do Almoço – CEEP-PLG

O **Sistema Automatizado de Liberação da Fila do Almoço** é uma aplicação web desenvolvida como projeto acadêmico no Centro Estadual de Educação Profissional Professora Lourdinha Guerra (CEEP-PLG), localizado em Parnamirim/RN.

O sistema tem como objetivo automatizar e organizar o processo de liberação das turmas para a fila do almoço, estabelecendo uma ordem de atendimento de maneira organizada, transparente e equilibrada, contribuindo para a redução de conflitos e facilitando o trabalho da equipe responsável pela supervisão.

## Funcionalidades

- Cadastro e gerenciamento das turmas da instituição.
- Consulta das turmas cadastradas no sistema.
- Organização automática da ordem de liberação para o almoço.
- Controle da situação das turmas, identificando as que estão aguardando e as que já foram liberadas.
- Liberação das turmas pela equipe responsável.
- Rotação diária da ordem das turmas, evitando que as mesmas permaneçam sempre nas primeiras posições.
- Registro das liberações realizadas.
- Acompanhamento das informações por meio de um painel administrativo.
- Controle de acesso conforme as permissões do sistema.

## Tecnologias utilizadas

- **HTML5:** estrutura das páginas do sistema.
- **CSS3:** estilização e organização da interface.
- **JavaScript:** interatividade e lógica de funcionamento da fila.
- **PHP:** processamento das informações e comunicação com o banco de dados.
- **MySQL:** armazenamento e gerenciamento dos dados.
- **Bootstrap:** recursos para construção e organização da interface.

## Organização do sistema

O sistema é desenvolvido para atender às necessidades da equipe responsável pelo acompanhamento da fila do almoço, permitindo o gerenciamento das informações e a execução das liberações.

- **Supervisão:** responsável por acompanhar a ordem das turmas e realizar as liberações para o almoço.
- **Administração:** responsável pelo gerenciamento das informações e dos cadastros necessários ao funcionamento do sistema.

## Objetivo do projeto

O projeto busca modernizar e facilitar o processo de organização da fila do almoço no CEEP-PLG, utilizando critérios objetivos para a liberação das turmas. Dessa forma, pretende contribuir para uma distribuição mais equilibrada das posições, melhorar o acompanhamento das liberações e otimizar as atividades da equipe responsável.

## Segurança

O sistema utiliza mecanismos de controle de acesso e armazenamento de informações em banco de dados. As credenciais de acesso e configurações internas de conexão não fazem parte deste repositório público.
